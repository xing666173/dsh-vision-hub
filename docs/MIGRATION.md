# 迁移指南

从旧版 dsh-tool-vision / 旧桥接格式迁移到 dsh-vision-hub 的说明。

## 从上游 dsh-tool-vision(0.3.x / v0.5.0)迁移

- **配置兼容**:`tool-vision` 命名空间的设置项完全兼容(12 项,含上游的
  bridgePreview 相关项无需配置——本增强版以独立 bridge-preview 插件提供
  预览,默认可用);
- **行为变化**:
  - 桥接文本变为 `[图片: <路径>]` 短标记(旧长指令格式的会话历史仍可
    预览与调用,无需清理);
  - 新增 14 个 `vision_*` 工具,直接可用;
  - inspect_image 行为不变;
- **依赖**:需可解析 sharp / potrace / puppeteer-core;缺失时仅相关工具
  降级并提示安装命令。

## 从旧 dsh-vision-hub(router 移植版)迁移

- 旧版内容(五级降级链、独立设置卡)已整体移除;
- 新架构:单端点 + 12 项原生设置 + 14 工具;
- 若旧配置中配置过 `provider` / `httpProviders` 等字段,请删除(新版本
  Config 不再包含,多余字段会被忽略)。

## 桥接导出文件说明

- 新文件名已消毒(`:` → `_`),不再产生 NTFS ADS 路径;
- 旧文件(含冒号文件名)仍可被读取,系统清理 temp 后失效属预期;
- 启动时自动清理 7 天前的导出文件。

## 回滚

- 内置插件场景:保留旧版文件副本,替换回即可;
- 设置回滚:备份 `settings.yaml` 后修改;12 项设置与旧版完全兼容,
  一般无需回滚。
