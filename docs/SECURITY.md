# 安全说明

## 图片桥与预览

- 桥接导出目录默认 `<tmp>/dsh-vision-bridge`,**仅该目录内的文件**可通过
  预览回环路由读取;
- 预览路由校验:仅本机 Host(127.0.0.1/localhost/[::1])、仅图片扩展名
  (png/jpg/jpeg/webp/gif/avif/bmp)、单文件 ≤ 20MB、路径 containment;
- 桥接导出文件名已消毒(消除 NTFS ADS 冒号陷阱),写前内容比对防覆盖;
- 启动时清理 7 天前的导出文件。

## 工具文件访问

- 相对路径输入必须解析在会话工作区内(`../` 逃逸直接拒绝);
- 读取前 stat 预检,文件与附件路径统一 20MB 上限;
- 产物写入 `<工作区>/.dsh-tool-vision/`,不做越权写。

## 视觉调用

- 图片以 data URL(base64)发送,注意隐私与大小;
- 端点内容安全拒绝返回 `VISION_CONTENT_FILTERED`,提示换图而非重试;
- 限流/5xx 自动退避重试(最多 3 次),失败以结构化错误返回,不污染缓存。

## HTML 截图

- 仅允许本地 .html/.htm 文件;
- **网络默认禁用**:只放行 file:/data:/blob: 子资源,其余请求一律中断
  (防恶意本地页外联/拉取远程资源)。

## 报告问题

发现安全相关缺陷,请通过 GitHub issue 提交,并附复现步骤。
