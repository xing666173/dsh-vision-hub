## 与 dsh-vision-router 的关系

| 维度 | router | 本仓库 |
|---|---|---|
| 工具语义(提示词/参数契约/像素处理) | ✅ 来源 | ✅ 完整保留 |
| provider 链/模型路由 | ✅ 重型 | ❌ 砍掉(单端点) |
| 本地模型(Ollama/LM Studio) | ✅ | ❌ |
| 独立设置卡 | ✅ | ❌(EAC 原生设置) |
| 渐进式工具挂载 | ✅ | ❌(工具直接可用) |

取舍原则:**保留「效果」,砍掉「复杂度」**——视觉识别质量不降,使用门槛大幅降低。

## bridge-preview / file-drop

- bridge-preview:纯展示层,模型侧文本完全不变;新老桥接标记格式都识别;
- file-drop:与视觉桥接互补(图片走视觉,文档走路径)。
