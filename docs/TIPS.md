# 使用技巧

## 让模型看得更准

- **问具体问题**:`vision_describe` 的问题越具体,回答越准
  (「按钮在什么坐标」优于「看看这张图」);
- **先定位再裁剪**:大图细节看不清时,先 `vision_ground` 拿到坐标,再
  `vision_crop` 裁出小区域单独看——比让模型硬读整张大图可靠;
- **结构化输出**:需要证据清单时用 `vision_describe(json=true)`,返回
  summary/layout/entities/text 结构化 JSON。

## 长截图处理

- `vision_long_screenshot_ocr` 适合聊天记录/长文档:自动分块、逐块转写、
  拼接 Markdown + manifest;
- 图太宽(>4MP 单块)会自动横向切块,无需手动处理;
- 单次任务有 120s 总预算与 40 块上限,超长内容建议分段截取。

## 限流与免费端点

- 免费端点高峰 429 是常态:插件自动退避重试 3 次,仍失败稍后再试;
- 准备两个端点配置(如智谱 + 百炼),高峰期切换只需改 settings 三项;
- 内容安全被拒(敏感图)时换图即可,不要反复重试同一张。

## 与多模态模型的配合

- `multimodalModels` 白名单内的模型直收图片块,不走桥接——同一配置可服务
  纯文本与多模态两类会话;
- 纯文本会话里,桥接标记 + 系统提示规则保证模型照常调用视觉工具。

## 隐私提醒

- 图片通过 base64 发送到视觉端点,敏感内容请使用本地端点(Ollama)或
  自建兼容服务;
- HTML 截图默认禁网,页面里的远程资源不会加载,也不会外联回传。

## 排查顺序

报错时按此顺序定位:端点可达性(直接 curl /chat/completions)→
`maxTokens` 是否超上限 → 图片格式/大小(极小图、>20MB)→ 内容安全过滤
(`VISION_CONTENT_FILTERED`)→ 依赖缺失(sharp/potrace/puppeteer-core)。
